## What's Actually on Offer

BlueVPS runs three main VPS product lines, all using KVM virtualization:

- **bKVM** — HDD-based with RAID-10, the cheapest entry point
- **SSD-bKVM** — Solid state drives from Samsung, Kingston, and Intel; faster read/write
- **HD-KVM** — Heavier-duty plans with more RAM and storage, powered by dual Intel Xeon E5

All plans come with unlimited bandwidth, 1 Gbps ports, at least one IPv4 and four IPv6 addresses, VNC access, and SSH. Both Linux and Windows operating systems are supported. Control panel options include DirectAdmin, cPanel, ISPmanager, VestaCP, and VirtualMin — some free, some paid add-ons.

The network infrastructure is modern where it counts: newer configurations run AMD EPYC and Intel Xeon Silver Scalable processors alongside NVMe drives, and the port connections sit at 10 Gbit on updated hardware.
